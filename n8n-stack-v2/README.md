# 🚀 n8n Stack v2: Оптимизированная установка для n8n 2.x

Этот установочный пакет предназначен для развертывания **n8n версии 2.x** с учетом всех особенностей новой архитектуры Task Runners. 

> [!IMPORTANT]
> Версия v2.x требует специфических настроек сети Docker для корректной работы JavaScript-узлов. Этот скрипт настраивает их автоматически.

## ✨ Новые возможности v2
- **Полная поддержка n8n 2.9.x+**: Включает правильную настройку брокера задач (`0.0.0.0`).
- **Умный Апгрейд**: Скрипт детектирует старые установки n8n v1 и предлагает автоматическую миграцию без потери данных.
- **Ежемесячное Автообновление**: Опциональная настройка системного таймера (`systemd`), который 1-го числа каждого месяца обновляет образ n8n до последней версии.
- **Оптимизация производительности**: Конкурентность воркеров (Concurrency) установлена в значение `5` для стабильной работы.
- **Изоляция кода**: Включена защита песочницы (`N8N_BLOCK_ENV_ACCESS_IN_NODE`).

## 🛠 Требования
- Чистый сервер или сервер с уже установленным n8n v1.
- Минимум **2 ГБ ОЗУ**.
- Домен с настроенной A-записью.

## 🚀 Установка / Обновление

```bash
git clone https://github.com/Comandosai/comandos-deploy-hub.git
cd comandos-deploy-hub/n8n-stack-v2
sudo ./setup.sh
```

## 📋 Управление
- `./setup.sh --stop` — остановить n8n.
- `./setup.sh --logs` — просмотр логов основного процесса n8n.

## 📁 Структура папок
- `n8n_data/` — настройки и workflow.
- `postgres_data/` — база данных PostgreSQL 16.
- `redis_data/` — кэш и очередь воркера.
- `output/` — общая папка для файлов (в n8n доступна как `/data/output`).

## 🛡 Безопасность
Все пароли и ключи шифрования генерируются автоматически при первой установке. Доступ к БД ограничен внутренней сетью Docker.

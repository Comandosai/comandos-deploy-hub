# Данные для развертывания

Заполните только то, что знаете. Остальное агент должен найти сам или спросить отдельно.

Это главный канонический файл входных данных для всего сценария.

Если файла нет, агент должен создавать именно этот полный шаблон целиком, а не урезанную версию под текущий этап.

## Заполните только это

- `server_access:` 
- `x_license_key:` 
- `n8n_domain:` 
- `admin_email:` 
- `n8n_admin_password:` 
- `openai_api_key:` 
- `openrouter_api_key:` 
- `telegram_sales_bot_token:` 
- `telegram_error_bot_token:` 

## Остальное агент должен найти сам, если сможет

- `supabase_dashboard_url:` 
- `supabase_admin_email:` 
- `supabase_admin_password:` 
- `db_host:` 
- `db_port:` 
- `db_name:` 
- `db_user:` 
- `db_password:` 
- `db_schema:` public
- `tenant_id:` global

## Правило для агента

- сначала читать этот файл;
- не спрашивать повторно уже заполненные поля;
- спрашивать только то, чего здесь нет;
- поле `admin_email` использовать и как почту для SSL, и как `n8n` admin email, если отдельно не указано иное;
- если `n8n` или `Supabase` уже найдены на сервере, дописывать сюда найденные URL, логины, пароли и DB-параметры;
- после каждого этапа предлагать только один следующий шаг.

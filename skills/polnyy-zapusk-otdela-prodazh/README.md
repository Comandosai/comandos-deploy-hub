# Полный запуск отдела продаж

Это верхнеуровневый навык, который ведет пользователя через весь сценарий внедрения как через один проект.

Что делает:
- читает общий файл входных данных проекта;
- читает общий файл контекста внедрения;
- понимает, что уже готово;
- определяет следующий релевантный этап;
- предлагает только один следующий шаг;
- направляет пользователя в нужный поднавык;
- после завершения этапа обновляет контекст и ведет дальше.

## Когда использовать

Использовать, когда нужно не просто выполнить один этап, а вести весь проект внедрения как единый сценарий:
- `n8n`
- база знаний и векторизация
- подключение отдела продаж
- Telegram-тестирование

## Как агент должен вести пользователя

После каждого этапа агент должен:
- проверить текущее состояние;
- обновить общий файл контекста;
- понять, какой шаг уже выполнен;
- пропустить уже готовые этапы;
- предложить только один следующий шаг;
- выдать этот шаг в готовом `text`-блоке;
- если есть достаточно данных, предложить продолжить без лишнего ввода.

## Команда 1. Скачать и установить навык

```text
Скачай и установи навык `Полный запуск отдела продаж` из репозитория `https://github.com/Comandosai/comandos-deploy-hub`, директория `skills/polnyy-zapusk-otdela-prodazh`.

Адаптируй установку под текущего агента:
- если это Codex, положи файлы в codex-совместимую skill-структуру;
- если это Claude, положи файлы в claude-совместимую структуру;
- если это Antigravity, положи файлы в antigravity-совместимую структуру.

Установи:
- bundle entrypoint;
- references;
- manifest;
- все файлы верхнеуровневого навыка-оркестратора.

После установки ничего не запускай автоматически.
Просто покажи, что навык установлен, и предложи первый релевантный шаг по текущему состоянию проекта.
```

## Команда 2. Начать общий сценарий

```text
Используй навык `Полный запуск отдела продаж`.

Сначала:
- прочитай `DANNYE_DLYA_RAZVERTYVANIYA.md`, если он есть;
- прочитай `KONTEXT_VNEDRENIYA_OTDELA_PRODAZH.md`, если он есть;
- если файла контекста нет, создай его;
- определи, какие этапы уже выполнены;
- не заставляй меня вручную выбирать следующий шаг.

После этого:
- предложи только один следующий релевантный этап;
- выдай его в готовом `text`-блоке;
- если можно продолжать автоматически, прямо предложи это.
```

## Команда 3. Продолжить сценарий без ручной навигации

```text
Продолжай общий сценарий внедрения.

Используй текущий контекст проекта, не возвращайся к уже выполненным этапам и предложи следующий релевантный шаг.
Если следующий шаг уже можно делать без новых данных от меня, предложи продолжить сразу.
Обнови `KONTEXT_VNEDRENIYA_OTDELA_PRODAZH.md` после завершения этапа.
```

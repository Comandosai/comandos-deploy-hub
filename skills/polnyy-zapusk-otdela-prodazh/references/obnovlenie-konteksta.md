# Правила обновления контекста

После завершения каждого этапа нужно обновлять файл `KONTEXT_VNEDRENIYA_OTDELA_PRODAZH.md`.

Обновлять нужно:
- статусы этапов;
- найденные компоненты;
- уже подключенные части системы;
- следующий рекомендованный навык;
- следующее рекомендованное действие.

Если этап завершен успешно, его статус должен быть `done`.
Если этап начат, но не завершен, статус должен быть `in_progress`.
Если этап еще не начинался, статус должен быть `not_started`.

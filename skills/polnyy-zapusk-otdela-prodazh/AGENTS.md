# Полный запуск отдела продаж

Этот пакет нужен как верхнеуровневый оркестратор всего внедрения:
- читает общие входные данные;
- читает общий контекст внедрения;
- понимает текущее состояние;
- предлагает следующий релевантный шаг;
- ведет пользователя через все остальные навыки.

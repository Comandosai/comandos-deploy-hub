# Развертывание COMANDOS Hermes

Навык для установки COMANDOS Hermes на VPS.

Быстрая команда для папки `Hermes`:

```bash
curl -fsSL https://raw.githubusercontent.com/Comandosai/comandos-deploy-hub/main/stacks/hermes/install.sh | bash
```

После этого заполнить `comandos-hermes.env` и выполнить:

```bash
./deploy.sh
```

Лицензия вводится при входе в панель.

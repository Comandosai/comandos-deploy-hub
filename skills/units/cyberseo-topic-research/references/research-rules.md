# Правила поиска тем

Искать не просто список статей, а группы:

- главная тема;
- подтемы вокруг неё;
- связь подтем с главной темой.

## Источники

Приоритет:

1. Уже имеющиеся темы и опубликованные статьи CyberSEO.
2. Wordstat через `POST /api/v1/wordstat/top`, если он настроен.
3. Firecrawl, если есть ключ и лимит.
4. Обычный поиск в интернете, если Firecrawl недоступен.
5. Perplexity только как запасной способ расширить слишком узкую тему.

## Firecrawl

Firecrawl не обязателен.

Если ключ пустой, лимит закончился или запрос упал:

- не останавливать работу;
- записать это в отчёт;
- продолжить другими источниками.

Лимит страниц брать из `research.firecrawl_max_pages`. Если пусто, использовать 20.

## Wordstat

Для России и СНГ сначала пробовать реальные ключевые запросы.

Если Wordstat вернул пусто:

- не просить нейросеть “придумать ключи”;
- попробовать расширить тему через Perplexity, если он включён;
- если спроса всё равно нет, тему не импортировать.

## Год в теме

Для медицинских и вечнозелёных тем по умолчанию писать в `notes`:

```text
year_mode=forbidden
```

Год нужен только там, где без него смысл теряется: законы, тарифы, изменения, обзоры рынка, новые правила.

## Что показать перед импортом

Сначала вывести понятный список:

- главная тема;
- подтемы;
- страна и город;
- почему тема не дубль;
- какие темы пропущены.

Если пользователь сказал “импортируй сразу”, можно импортировать без отдельного подтверждения, но всё равно сохранить отчёт.

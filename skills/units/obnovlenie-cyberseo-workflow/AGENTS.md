# Обновление CyberSEO workflow

Сначала прочитай `SKILL.md`.

Рабочий путь:

```bash
python3 scripts/update_cyberseo_workflows.py --ssh-host <host>
```

Если пользователь дал только сервер, больше ничего не спрашивай. Найди `n8n`, сделай резервную копию, перенеси `table` и `domen`, импортируй workflow, свяжи их между собой и проверь результат.

Сначала настрой вход по SSH-ключу, если он ещё не работает. После настройки напиши пользователю команду входа на сервер. Приватный ключ не показывай.

`table` и `domen` не проси сразу. Сначала найди старый `ВФ 0`; если точного имени нет, ищи любой workflow с узлом `Установка ID таблицы`.

Важно: `table` и `domen` искать только в базе n8n, таблица `workflow_entity`, поле `nodes`, узел `Установка ID таблицы`. Не лезь в `.env`, docker compose, логи и папки сервера ради этих двух значений.

Точный смысл поиска: в шаблоне это `assets/workflows/CyberSEO - ВФ 0_ МАСТЕР.json`, строки 139-148 (`table`, `domen`) и строка 162 (`Установка ID таблицы`). В живом n8n это тот же узел внутри `workflow_entity.nodes`.

Правило включения: для `n8n` 2.x и выше опубликуй и включи `ВФ 0-4`; для `n8n` ниже 2.x включи только `ВФ 0`.

Не печатай секреты и полные JSON workflow.

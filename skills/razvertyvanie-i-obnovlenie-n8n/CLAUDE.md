# Развертывание и обновление n8n

Используй этот пакет, когда нужно:
- проверить, есть ли уже `n8n`;
- поставить новый `n8n` через `n8n-stack-v2`;
- обновить уже установленный `n8n`;
- собрать только недостающие параметры и не спрашивать лишнее.

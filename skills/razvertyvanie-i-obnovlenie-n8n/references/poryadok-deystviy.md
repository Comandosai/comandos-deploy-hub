# Порядок действий

## Шаг 1. Подключиться к серверу

Нужно:
- получить доступ к серверу;
- проверить, есть ли `n8n`;
- проверить, есть ли следы `n8n-stack-v2`;
- проверить путь `/root/n8n`.

## Шаг 2. Выяснить сценарий

Если `n8n` уже установлен:
- обязательно спросить, нужно ли обновление.

Если `n8n` не установлен:
- идти в новую установку.

## Шаг 3. Собрать недостающие параметры

Нужно запросить только то, чего не хватает:
- домен;
- почту для SSL;
- пароль администратора;
- при необходимости `x-license-key`.

## Шаг 4. Запустить `n8n-stack-v2`

Нужно использовать только `n8n-stack-v2`.

## Шаг 5. Проверить результат

Нужно проверить:
- контейнеры;
- домен;
- SSL;
- доступность интерфейса.

## Шаг 6. Дать отчет

В конце коротко сказать:
- новая установка или обновление;
- какой домен используется;
- где лежит стек;
- что делать дальше.

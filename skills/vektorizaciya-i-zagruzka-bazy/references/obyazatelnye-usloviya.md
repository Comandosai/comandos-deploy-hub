# Обязательные условия

## Что нужно для нормального сценария

- папка с исходными документами;
- доступ к `Supabase` или к серверу, где он стоит;
- рабочий лицензионный ключ `COMANDOS`;
- execution host с доступом к `api.comandos.ai`.

## Что важно

- основной runner должен запускаться локально, там, где есть документы и интернет;
- `Supabase` — это хранилище, а не основное место выполнения ingestion;
- если хост с доступом к базе не имеет выхода в интернет, допускается гибридный режим.

## Что должно получиться

- `docs` должны быть структурированы;
- giant chunks должны быть разбиты на нормальные смысловые секции;
- `products_live` должна строиться только из factual rows;
- `tenant_id` по умолчанию должен быть `global`, если пользователь не указал другой.

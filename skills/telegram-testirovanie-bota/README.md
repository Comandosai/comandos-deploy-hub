# Telegram-тестирование бота

Этот навык нужен для автоматических и полуавтоматических тестов Telegram-бота на реальном клиентском контексте.

Что делает:
- ставит зависимости для Telegram harness;
- поднимает пользовательскую Telegram-сессию;
- собирает контекст из папки клиента;
- проводит серию тестовых сообщений;
- сохраняет отчет по качеству.

## Что потребуется

Обязательно:
- локальная папка с документами клиента или готовый `__workspace/docs`;
- Telegram-бот для проверки;
- возможность пройти вход в Telegram при первом запуске.

Опционально:
- количество тестов;
- режим тестов: обычный, с подвохом, стресс.

## Откуда брать входные данные

По умолчанию навык должен сначала искать в корне проекта файл `DANNYE_DLYA_RAZVERTYVANIYA.md`.

Если файл найден:
- читать оттуда `telegram_bot_token` и связанные данные;
- не спрашивать повторно уже заполненные поля.

Если файла нет:
- спрашивать только недостающее.

## Команда 1. Скачать и установить навык

Скопируйте и вставьте агенту:

```text
Скачай и установи навык `Telegram-тестирование бота` из репозитория `https://github.com/Comandosai/comandos-deploy-hub`, директория `skills/telegram-testirovanie-bota`.

Адаптируй установку под текущего агента:
- если это Codex, положи файлы в codex-совместимую skill-структуру;
- если это Claude, положи файлы в claude-совместимую структуру;
- если это Antigravity, положи файлы в antigravity-совместимую структуру.

Установи:
- bundle entrypoint;
- `scripts/`;
- `references/`;
- все файлы навыка для Telegram harness и сохранения отчета.

После установки ничего не запускай автоматически.
Просто покажи, что навык установлен, и скажи, какой следующей командой запускать подготовку тестирования.
```

## Команда 2. Подготовить тестирование

Скопируйте и вставьте агенту:

```text
Используй навык `Telegram-тестирование бота`.

Сначала подготовь среду:
- проверь `python3`;
- установи зависимости из `scripts/requirements.txt`, если их нет;
- подготовь локальную Telegram user-сессию;
- если вход еще не выполнен, запроси у меня телефон, код и 2FA только по необходимости.

После этого скажи, что среда готова к тесту.
```

```text
Используй навык `Telegram-тестирование бота`.

Возьми документы из папки `/путь/к/документам_клиента`.
Собери компактный контекст для тестов.

После этого покажи:
- сколько файлов попало в контекст;
- где сохранен manifest;
- где сохранен bundled context.
```

## Команда 4. Провести тесты

Скопируйте и вставьте агенту:

```text
Используй навык `Telegram-тестирование бота`.

Проведи 5 тестов Telegram-бота `@username_бота` на основе текущего контекста.

Правила:
- один исходящий тестовый месседж за раз;
- ждать ответ;
- анализировать каждый ответ;
- проверить обычные вопросы, вопросы по товарам, вопросы с подвохом и неполными данными.

После завершения дай краткий отчет и сохрани полный JSON-отчет рядом с клиентским кейсом.
```


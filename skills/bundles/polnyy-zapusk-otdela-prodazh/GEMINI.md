# Полный запуск отдела продаж

Этот пакет ведет внедрение по фиксированному сценарию.

Правило:
- ориентир — `README.md` этого навыка;
- команды в разделе `Команда 1..12` выполнять по порядку;
- не пересказывать шаги по памяти, не ужимать сценарий.
- каждый шаг брать из блока `Команда N` в `README.md` без смысловых потерь.

Обязательная последовательность:
1. Установка
2. `n8n`
3. `Supabase`
4. Подготовка документов
5. Отдельная загрузка документов
6. Подключение отдела продаж
7. Telegram-тестирование
8. `brief`
9. Промпт квалификатора
10. Промпт консультанта
11. Вставка промптов
12. Финальный тест после выключения `06_WF_Test`

- [SKILL.md](SKILL.md)

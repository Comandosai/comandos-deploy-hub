# Полный запуск отдела продаж

Этот пакет — верхнеуровневый маршрут всего внедрения.

Главное правило:
- источник истины — только `README.md` этого навыка;
- выполнять сценарий по разделам `Команда 1` ... `Команда 16`;
- не сокращать шаги и не переставлять порядок без явной причины из контекста проекта.
- каждый следующий шаг брать из соответствующего блока `Команда N` в `README.md`, а не пересказывать по памяти.

Как работать:
1. Сначала прочитать `README.md` целиком.
2. Определить текущий этап по `DANNYE_DLYA_RAZVERTYVANIYA.md` и `KONTEXT_VNEDRENIYA_OTDELA_PRODAZH.md`.
3. Взять следующий шаг строго из блока `Команда N` в `README.md` и передать его без смысловых сокращений.
4. После каждого шага выдать пользователю только один следующий шаг в готовом `text`-блоке.

Обязательный порядок этапов:
1. Установить навык.
2. `n8n`.
3. `Supabase`.
4. Подготовка документов.
5. Отдельный ingestion.
6. Подключение отдела продаж.
7. Telegram-тест.
8. `brief`.
9. Промпт квалификатора.
10. Промпт консультанта.
11. Вставка промптов в боевые `workflow`.
12. Выключение `06_WF_Test` и финальный тест.
13. Снятие структуры `AmoCRM`.
14. Сборка CRM-карты `AmoCRM`.
15. Сборка `AmoCRM`-промптов и workflow.
16. `AmoCRM` sales-тест.

Основные файлы:
- [SKILL.md](SKILL.md)
- [README.md](README.md)

# Руководство по стилям (CSS Guide) 🎨

Этот файл описывает архитектуру стилей в теме `autopipe-blog`.
Мы используем подход **Mobile-First**.

## Главное правило
**Сначала пишем для телефона, потом улучшаем для компьютера.**
Никаких `max-width` для мобильных версий!

---

## Структура файла `critical-wp.css`

### 1. Базовые стили (Mobile Default)
Код, написанный в корне файла, применяется **ВСЕГДА**.
Здесь мы пишем стили для самых маленьких экранов (iPhone SE, Android).

```css
/* Пример: Заголовок для телефона */
.post-title {
    font-size: 24px;
    margin-bottom: 10px;
}
```

### 2. Планшеты (Tablet)
Блок `@media (min-width: 768px)`.
Сюда пишем изменения для iPad и вертикальных планшетов.

```css
@media (min-width: 768px) {
    .post-title {
        font-size: 32px; /* Чуть крупнее */
    }
}
```

### 3. Десктоп (Desktop Isolation) 🖥️
Блок `@media (min-width: 1024px)`.
Здесь живет весь "взрослый" дизайн: 3 колонки, большие отступы, огромные шрифты.

```css
@media (min-width: 1024px) {
    .post-title {
        font-size: 56px; /* Огромный заголовок для ПК */
        margin-bottom: 40px;
    }

    .posts {
        grid-template-columns: repeat(3, 1fr); /* 3 колонки */
    }
}
```

## Как вносить правки (Примеры)

### Задача: "Увеличь шрифт заголовка на компьютере"
**Где писать:** Внутри `@media (min-width: 1024px)`.
**Почему:** Если написать просто в корне, шрифт станет огромным на телефоне, и верстка разъедется.

### Задача: "Поменяй цвет кнопки везде"
**Где писать:** В самом начале файла (Base Styles).
**Почему:** Это глобальное изменение, оно должно примениться ко всем устройствам.

### Задача: "Скрой этот блок на телефоне"
**Как делать:**
```css
/* В начале файла (Mobile) */
.my-block { display: none; }

/* В блоке Desktop */
@media (min-width: 1024px) {
    .my-block { display: block; }
}
```

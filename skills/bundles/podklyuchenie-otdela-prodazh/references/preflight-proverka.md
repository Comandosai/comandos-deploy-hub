# Preflight-проверка

Перед любыми импортами и перепривязками навык обязан:

1. Подключиться к серверу через интерактивную SSH-сессию.
2. Проверить контейнеры `n8n` и базовую живость проекта.
3. Определить `project_id`.
4. Проверить, какие custom node packages уже установлены.
5. Проверить, какие credential types зарегистрированы.

Минимальный обязательный список:
- `@comandosai/n8n-nodes-amo-crm`
- `@comandosai/n8n-nodes-doc-extract`
- `comandosLsiKeysApi`

Если этого нет, навык не должен переходить к импорту workflow как будто все готово.

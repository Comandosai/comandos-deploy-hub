# Подключение отдела продаж

Этот пакет предназначен для установки и настройки существующего контура клиента:
- подключение `Supabase`;
- подключение `n8n`;
- загрузка workflow;
- создание соединений;
- настройка `MCP`;
- установка тестового агента проверки базы;
- при необходимости включение Telegram-тестирования.

Все рабочие инструкции находятся в:
- [SKILL.md](SKILL.md)

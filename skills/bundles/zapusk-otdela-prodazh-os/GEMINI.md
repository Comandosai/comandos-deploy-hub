# Запуск отдела продаж ОС

Открой `SKILL.md`, затем `README.md`.

Создай рабочие файлы `AGENTS.md`, `LAUNCH_ROADMAP.md`, `LAUNCH_STATE.json` и `PROJECT_NOTES.md` из `templates/`.
После этапа 0 остановись: не запускай Supabase, Telegram, базу знаний, prompts, amoCRM, smoke-test или deploy без отдельной команды пользователя.
Проводи запуск COMANDOS ОС по чеклисту: Supabase, база знаний, Telegram, исследование аудитории, подтверждение гипотезы владельцем, brief, стратегия рекомендаций, план данных, живая квалификация, qualification gate, prompts, amoCRM, CRM field gap, CRM-оператор, smoke-test.

В prompt-ах обязательно учитывай runtime-снимок фактов: что уже собрано, что пустое и какие required-факты блокируют консультацию.

Не раскрывай секреты и не отмечай шаг готовым без проверки.

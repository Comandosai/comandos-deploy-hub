# AGENTS.md - запуск отдела продаж COMANDOS

Эта папка - рабочее пространство распаковки отдела продаж COMANDOS для одной установки.

## Главный порядок

Перед любым действием прочитай:

1. `AGENTS.md`
2. `LAUNCH_ROADMAP.md`
3. `LAUNCH_STATE.json`
4. `PROJECT_NOTES.md`
5. `SKILL.md` скачанного пакета `zapusk-otdela-prodazh-os` в каталоге установленных skills

Если одного из рабочих файлов `AGENTS.md`, `LAUNCH_ROADMAP.md`, `LAUNCH_STATE.json` или `PROJECT_NOTES.md` нет, сначала восстанови его из шаблона skill-пакета и только потом продолжай.

## Что здесь делается

Здесь по шагам запускается отдел продаж COMANDOS ОС:

1. установка skill и подготовка рабочих файлов;
2. Supabase;
3. Telegram;
4. база знаний и brief;
5. prompt квалификатора;
6. prompt консультанта;
7. amoCRM и CRM snapshot, если нужен CRM-контур;
8. CRM field gap и правила стадий;
9. prompt CRM-оператора;
10. финальная проверка.

Каждый следующий этап запускается только после явной команды пользователя.

Если пользователь просит выполнить поздний этап, а ранний gate не закрыт, сначала вернись к раннему gate и объясни, что именно мешает идти дальше.

## Стоп-правила

- Не разворачивай Supabase без отдельной команды.
- Не запускай базу знаний, векторизацию, prompt-ы и smoke-test, если Supabase нужен, но не доказано, что COMANDOS ОС может подключиться к базе.
- Если Supabase найден на SSH/VPS, внутренний Docker-host вроде `db:<port>` не считается готовой строкой для внешнего кабинета.
- Не подключай Telegram без отдельной команды.
- Не запускай Telegram smoke-test без отдельной команды.
- Для Telegram smoke-test используй только скрипты свежего `zapusk-otdela-prodazh-os`. Не устанавливай старый `telegram-testirovanie-bota`, не создавай n8n test workflow и не используй `06_WF_Test`.
- Не собирай базу знаний, brief и prompt-ы без отдельной команды.
- Не подключай amoCRM и не делай deploy без отдельной команды.
- Не используй старые skills `polnyy-zapusk-otdela-prodazh`, `podklyuchenie-otdela-prodazh` и старые n8n-сценарии запуска.
- Если старый skill уже установлен локально, скачай свежий `zapusk-otdela-prodazh-os` через COMANDOS Skills Gateway и работай только по нему.

## Секреты

Нельзя сохранять в файлы и печатать полностью:

- license key;
- Telegram bot token;
- Supabase connection string;
- amoCRM client secret;
- access token / refresh token;
- пароли и приватные ссылки.

В `LAUNCH_STATE.json` можно хранить только маски значений и признаки готовности.

License key можно увидеть один раз в install-команде и использовать только для установки. После установки не повторяй полный ключ в чате, отчете, командах проверки, markdown, логах или списке выполненных команд.

Не пиши команды проверки с реальным ключом, например `rg '<полный license key>' ...`. Если проверяешь отсутствие ключа в файлах, в ответе пиши только: "проверено: полный license key не сохранен", без значения ключа.

## Как вести запуск

После каждого действия обновляй:

- `LAUNCH_ROADMAP.md` - что готово и что осталось;
- `LAUNCH_STATE.json` - машинное состояние запуска;
- `PROJECT_NOTES.md` - важные решения, ограничения и ручные действия пользователя.

Отмечай пункт готовым только после проверки критерия готовности.

Пользователю всегда давай один следующий шаг, без пачки лишних задач.

## Git и файлы

Если рабочая папка не является Git-репозиторием, не делай commit и push.

Если Git-репозиторий есть, перед commit/push проверь:

1. remote и ветку;
2. что нет секретов;
3. что не добавлены сырые клиентские файлы, дампы, логи, `.env`, кэши и временные файлы;
4. что пользователь явно попросил commit/push.

Локальную папку `.comandos_os/`, Telegram `.session`, тестовые диалоги и отчеты нельзя коммитить. Если рабочая папка является Git-репозиторием, добавь `.comandos_os/` в локальные исключения Git до запуска Telegram-теста.

## Короткая проверка этапа 0

Этап 0 готов, если в рабочей папке есть:

- `AGENTS.md`;
- `LAUNCH_ROADMAP.md`;
- `LAUNCH_STATE.json`;
- `PROJECT_NOTES.md`;
- скачанный skill `zapusk-otdela-prodazh-os` доступен в каталоге установленных skills.

После этапа 0 остановись и спроси: переходим к Supabase или пока останавливаемся?

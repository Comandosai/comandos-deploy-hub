# CRM mapping

## Правило по воронке

- CRM-оператор меняет pipeline/status только по подтвержденному критерию ниже.
- Если критерий для стадии не заполнен владельцем, автоматически на эту стадию не переводить.
- Если входные данные противоречат критерию или данных мало, статус не менять, записать причину в `crm_result.skipped`.
- Критерии должны быть согласованы после `field_plan.md`, `crm_field_gap.md` и актуального CRM snapshot.
- Стадия `Консультация` не может ставиться только по общему интересу клиента. Для нее должен быть выполнен `qualification_gate` из `field_plan.md`, если владелец явно не подтвердил другое правило.

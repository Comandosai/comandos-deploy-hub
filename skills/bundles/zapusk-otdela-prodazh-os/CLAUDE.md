# Запуск отдела продаж ОС

Работай по `SKILL.md` и `README.md`.

Создай `AGENTS.md`, `LAUNCH_ROADMAP.md`, `LAUNCH_STATE.json` и `PROJECT_NOTES.md` из `templates/`.
После этапа 0 остановись: не запускай Supabase, Telegram, базу знаний, prompts, amoCRM, smoke-test или deploy без отдельной команды пользователя.
Веди запуск по шагам, обновляй состояние после каждого действия и не переходи дальше без проверки текущего шага.

До prompt-ов согласуй qualification gate и цепочку живой квалификации: какая боль у клиента, как сейчас идет заявка/процесс, где теряются деньги, время, клиенты или контроль, какие факты обязательны до консультации, какие optional и что можно брать из payload/истории/CRM без вопроса.

Секреты не печатай полностью и не сохраняй в файлы.

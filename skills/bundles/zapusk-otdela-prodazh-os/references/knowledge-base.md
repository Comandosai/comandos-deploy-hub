# База знаний

Цель: подготовить материалы клиента для исследования, brief и ответов консультанта.

## Если материалы есть

1. Сложи исходники в рабочую папку клиента.
2. Используй навык `vektorizaciya-i-zagruzka-bazy`.
3. Перед ingestion зафиксируй целевую схему: `sales_department`.
4. Если runner векторизации использует env, выставь `SUPABASE_DB_SCHEMA=sales_department`.
5. Нарежь материалы на чанки.
6. Проверь структуру чанков до записи:
   - каждый смысловой блок начинается с markdown-заголовка `#`, `##` или `###`;
   - после заголовка есть полезный текст до следующего заголовка;
   - пустые заголовки, заголовки без текста и цепочки заголовков без содержимого запрещены;
   - один чанк не смешивает разные смысловые темы, если их можно разделить.
7. Загрузи чанки в Supabase именно в `sales_department.knowledge_rag`.
8. Если есть товарные строки, загрузи их именно в `sales_department.products_live`.
9. Проверь, что записи появились не в `public`, а в `sales_department`.
10. Сделай контрольный поиск по 2-3 ключевым вопросам клиента через `sales_department.hybrid_search` или эквивалентный гибридный поиск отдела продаж.
11. Отметь базу знаний готовой.
12. Перед prompt-ами перейди к исследованию и brief: [research-brief-field-plan.md](research-brief-field-plan.md).

## Важно про схемы

Для запуска отдела продаж ОС источник правды - схема `sales_department`.

Не считай базу знаний готовой, если:
- runner записал данные только в `public.knowledge_rag`;
- `sales_department.knowledge_rag` пустая;
- нет проверенного поиска по `sales_department.hybrid_search` или эквивалентному запросу в этой же схеме.

`public.knowledge_rag` допустима только для старых или общих сценариев вне отдела продаж ОС.

## Если материалов нет

1. Не блокируй запуск полностью.
2. Собери минимальный brief.
3. Отметь в roadmap: `База знаний: нет исходных материалов`.
4. Продолжай к исследованию и brief, но добавь риск: консультант будет отвечать только по brief и внешнему исследованию, если интернет доступен.

## Критерий готовности

База знаний готова, если:
- источники разобраны;
- чанки загружены в `sales_department.knowledge_rag`;
- товарные строки, если они есть, загружены в `sales_department.products_live`;
- есть минимум одна проверенная запись именно в `sales_department`;
- гибридный поиск по базе знаний возвращает релевантный результат;
- агент понимает, какие источники использованы;
- ясно, какие выводы пришли из документов клиента, а какие из внешнего исследования.

# Логика roadmap

Roadmap - это рабочий чеклист запуска. Агент обязан обновлять его после каждого действия.

## Этап 0

Перед любыми подключениями создай рабочие файлы запуска:

- `AGENTS.md` из `templates/AGENTS.template.md`;
- `LAUNCH_ROADMAP.md` из `templates/LAUNCH_ROADMAP.template.md`;
- `LAUNCH_STATE.json` из `templates/LAUNCH_STATE.template.json`;
- `PROJECT_NOTES.md` из `templates/PROJECT_NOTES.template.md`.

После этого остановись. Supabase, Telegram, база знаний, prompts, amoCRM, smoke-test и deploy запускаются только по отдельной команде пользователя.

## Правило отметки

Пункт можно отмечать `[x]` только если выполнен критерий готовности.

Если действие начато, но не проверено, оставь `[ ]` и добавь строку `Статус: в работе`.

## Порядок

1. Режим запуска.
2. Supabase discovery: cloud, self-hosted SSH/VPS, готовая внешняя строка или не нужен.
3. Supabase readiness gate: внешнее подключение для COMANDOS ОС, SQL, схема, таблицы.
4. База знаний.
5. Telegram.
6. Исследование аудитории, болей и конкурентов.
7. Подтверждение гипотезы владельцем.
8. Brief.
9. Модель продажи, стратегия рекомендаций и план данных для диалога.
10. Цепочка живой квалификации: боль, путь заявки/процесса, последствия, решение.
11. Порог консультации: какие факты обязательны до `consultation`, какие optional, что брать из payload/истории/CRM.
12. Prompt квалификатора.
13. Prompt консультанта.
14. amoCRM.
15. CRM snapshot.
16. CRM field gap и повторный snapshot, если поля менялись.
17. Правила CRM и критерии стадий.
18. Prompt CRM-оператора.
19. Финальная проверка.

## Если пользователь перескочил этап

Не выполняй поздний этап "в долг".

Пример: пользователь сначала попросил векторизовать базу, а потом выяснилось, что кабинет не подключается к Supabase. Правильное действие - вернуться к Supabase readiness gate, зафиксировать блокер и дать один следующий шаг по подключению. Нельзя считать базу знаний готовой, пока COMANDOS ОС не может читать эту базу.

## Стоп-условия

Не переходи дальше, если:
- Supabase connection string не проверен;
- Supabase deployment mode не определен;
- Supabase работает только внутри SSH/Docker-сети, но внешняя строка для COMANDOS ОС не проверена;
- SQL-схема не применена;
- Telegram token не прошел `getMe`;
- исследование аудитории не сохранено или явно не зафиксировано, что интернет недоступен;
- владелец не подтвердил или не поправил гипотезу по бизнесу;
- brief не сохранен;
- модель продажи и стратегия рекомендаций не согласованы;
- field plan не сохранен;
- цепочка живой квалификации не согласована: неизвестно, какие боли искать, как выяснять текущий путь и какие последствия фиксировать;
- qualification gate не согласован: неизвестно, какие факты блокируют переход в консультацию;
- prompt не сохранен отдельным файлом;
- amoCRM подключение не подтверждено кабинетом;
- CRM snapshot не создан;
- CRM field gap не согласован;
- пользователь не согласовал CRM mapping.

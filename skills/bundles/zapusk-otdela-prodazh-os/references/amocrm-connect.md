# amoCRM

Цель: подключить amoCRM к COMANDOS ОС и открыть сборку CRM-оператора.

## В кабинете

1. Открыть COMANDOS ОС -> Отдел продаж -> amoCRM.
2. Скопировать webhook URL, если он нужен для входящих событий.
3. Скопировать callback URL для настройки OAuth-интеграции.
4. Ввести subdomain, client id, client secret.
5. Нажать `Подключиться`.
6. Пройти авторизацию amoCRM.
7. Вернуться в кабинет.
8. Проверить, что кабинет показывает подключенную компанию.

## После подключения

CRM-оператор должен перейти в состояние `нужна настройка`.

Пользователь копирует setup-команду CRM-оператора и вставляет ее в агента.

Агент обязан:
- обратиться к AmoCRM MCP;
- использовать только license key / setup key, если он уже подставлен кабинетом;
- собрать snapshot;
- не раскрывать токены;
- сохранить `amocrm_snapshot.json`;
- спросить у пользователя правила CRM;
- собрать финальный `crm_operator_prompt.md`.

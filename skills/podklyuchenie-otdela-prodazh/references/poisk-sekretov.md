# Поиск секретов

По умолчанию секреты надо искать автоматически до запроса пользователю.

Где искать:
- `.env`
- docker env
- рабочие каталоги проекта
- конфиги стека

Результат надо делить на две группы:
- `нашел и привязал`
- `не нашел, нужно спросить у пользователя`

Запрашивать у пользователя надо только то, что реально не найдено автоматически.

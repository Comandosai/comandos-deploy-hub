# Запуск через ИИ-агента

Сценарий для пользователя: человек объясняет задачу обычным текстом, а агент помогает подготовить Telegram-сессию, найти нужные чаты, заполнить конфигурацию и запустить сбор.

## Что должен сделать агент

1. Проверь, что ты находишься в папке `telegram-parser-starter`.
2. Прочитай `START_PROMPT.md`, `TASK_EXAMPLES.md` и `README.md`.
3. Если `.venv` ещё нет, запусти:

```bash
bash setup.sh
```

4. Проверь Telegram-сессию:

```bash
source .venv/bin/activate
python scripts/auth.py
```

5. Если терминал просит телефон, код или 2FA, спрашивай у пользователя по одному значению и передавай его в терминал.
6. Не сохраняй телефон, код и 2FA в файлы.
7. После успешного входа убедись, что сессия лежит внутри проекта в `sessions/`.
8. Если пользователь уже дал задачу, выполни её. Если задачи ещё нет, спроси:

```text
Telegram-сессия готова. Что будем собирать и анализировать?
```

9. Для поиска нужных чатов сначала используй:

```bash
python scripts/list_sources.py
```

10. Заполни `sources.txt`.

Примеры строк:

```text
@channelname
-1001234567890
-1001234567890 | topic=456
https://t.me/c/1234567890/456/789
@groupname | keywords=заявка,срочно,ошибка
```

11. Для разового сбора запусти:

```bash
python scripts/collect_history.py --limit 500
```

12. Для постоянного мониторинга запусти:

```bash
python scripts/watch_live.py
```

13. Если в `.env` есть `DEEPSEEK_API_KEY`, после сбора запусти:

```bash
python scripts/analyze_deepseek.py
```

14. Если пользователь хочет получать уведомления в своего Telegram-бота:

- попроси токен бота от `@BotFather`;
- добавь его в `.env` как `TELEGRAM_BOT_TOKEN`;
- попроси пользователя написать `/start` своему боту;
- запусти `python scripts/check_bot.py`;
- возьми нужный `chat_id` и добавь его в `.env` как `TELEGRAM_NOTIFY_CHAT_IDS`;
- запусти `python scripts/check_bot.py` ещё раз, чтобы отправить тестовое сообщение.

15. В конце покажи пользователю, где лежат результаты:

```text
data/messages.csv
data/messages.jsonl
data/live_messages.csv
data/live_messages.jsonl
data/report.md
```

## Главное правило

Не заставляй пользователя вручную разбираться в структуре проекта. Веди его короткими шагами: авторизация, выбор чатов, запуск сбора, отчёт.

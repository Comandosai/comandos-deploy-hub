# Инструкции для агента

Это учебный проект Telegram-парсера.

Правила:

- Не переписывай проект с нуля.
- Сначала используй готовые скрипты из `scripts/`.
- Telegram-клиент работает через `Telethon`.
- Встроенный `api_id/api_hash` лежит в `src/tg_parser/defaults.py`.
- Личные данные пользователя хранятся только локально.
- Не коммить `.env`, `sources.txt`, `sessions/`, `data/`, `logs/`.
- Если пользователь хочет новую задачу, меняй настройки, промпт анализа или добавляй маленький отдельный скрипт.
- Основной сценарий урока: авторизация, выбор источников, сбор сообщений, отчёт.
- Если сессии ещё нет, запусти `python scripts/auth.py` и веди пользователя через телефон, код Telegram и 2FA по одному шагу.
- Телефон, код и 2FA не сохраняй в файлы и не вставляй в README или конфиги.
- После авторизации проверь, что сессия лежит в `sessions/`.
- Если пользователь ещё не дал задачу, спроси, что собирать и анализировать.
- Если пользователь хочет уведомления, настрой только `.env`: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_NOTIFY_CHAT_IDS`.
- Для поиска `chat_id` используй `python scripts/check_bot.py`.

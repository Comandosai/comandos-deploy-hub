# Аудит кнопок COMANDOS Hermes Workspace

Дата начала: 2026-06-04

## Чёткая цель

Найти в панели COMANDOS Hermes Workspace каждую видимую кнопку, ссылку и действие, нажать их как обычный пользователь, проверить видимый результат, свежие ошибки браузера, сетевые ошибки и серверные логи, если действие ходит на сервер. Если действие сломано — найти причину, исправить минимальным изменением, повторить проверку и зафиксировать итог. Если функция ещё не готова — кнопка должна быть скрыта или отключена с понятным русским объяснением. Работу считать готовой только тогда, когда по каждой найденной кнопке есть один из статусов: `OK`, `FIXED`, `DISABLED` или `HIDDEN`.

Коротко: человек нажимает кнопку, смотрит лог, проверяет, что всё чётко, выявляет ошибку и повторяет это для каждой кнопки панели.

## Правило проверки

Для каждой кнопки:

1. Открыть раздел.
2. Нажать кнопку.
3. Проверить видимое поведение.
4. Проверить свежие ошибки браузера.
5. Проверить серверные логи, если действие ходит на сервер.
6. Исправить причину, если действие сломано.
7. Повторить нажатие.
8. Зафиксировать итог.

## Статусы

- `OK` — работает.
- `FIXED` — была ошибка, исправлено и перепроверено.
- `DISABLED` — функция не готова, кнопка отключена с русским объяснением.
- `HIDDEN` — функция убрана из интерфейса до готовности.
- `TODO` — ещё не проверено.
- `FAIL` — ошибка найдена, исправление ещё не готово.
